# 山水墨龙

在浏览器里实时生成的水墨墨龙：龙、峰林、云海和天空都由代码现场算出，不加载任何外部模型或贴图。

**在线体验：** https://threerocks.github.io/ink-dragon/

- **画龙点睛**：龙先盘卧云上、有眼无珠，点它的眼睛，墨爆、龙吟，腾空而起
- **巡山 / 戏珠**：巡山时龙沿峰林绕飞；戏珠时用鼠标或手指引一颗火珠，龙追着珠子飞
- **时辰与天气**：晨、昼、暮、夜；晴、雨、雪、雷（闪电、雷声、震屏）
- **调龙**：身长、粗细、鹿角、鬃毛，飞速、风力、云雾；青绿 / 水墨 / 浅绛三种设色；“换一条龙”“换一片山”
- **留影**：存一张带题款和印章的图，或录六秒带声音的短片；可在画上落款
- **分享**：网址记着这条龙、这片山和所有设置，复制链接，别人打开是同一幅画
- **声音**：风声、龙吟、墨爆、雨、雷、古琴拨弦，全部由浏览器 WebAudio 现场合成，不用任何音频文件

技术：three.js（WebGL）。几何生成算法移植自配套的 Blender 水墨视频工具。
